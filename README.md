# Healthcare Analytics for Doctor Visits

## Project Overview

Healthcare Analytics for Doctor Visits is a data analytics project focused on understanding patient characteristics and doctor visit patterns using healthcare data.

The project uses Exploratory Data Analysis (EDA) and data visualization techniques to analyze factors such as age, gender, illness, health status, chronic conditions, reduced activity, and doctor visits.

---

## Problem Statement

Healthcare datasets contain information about patients, their health conditions, illnesses, and doctor visits.

Analyzing these factors together to understand patient visit patterns is challenging. This project aims to identify meaningful patterns and relationships between patient characteristics, health conditions, and doctor visits using data analytics and visualization.

---

## Project Objectives

- Explore and understand the healthcare dataset.
- Analyze patient demographics and healthcare characteristics.
- Study doctor visit patterns.
- Analyze the relationship between illness, health status, and doctor visits.
- Examine chronic conditions and reduced activity.
- Identify meaningful patterns using data visualization.

---

## Dataset

The dataset contains patient-level healthcare records related to doctor visits, demographic characteristics, health conditions, and healthcare-related factors.

### Key Variables

- Doctor Visits
- Gender
- Age
- Income
- Illness
- Reduced Activity
- Health Status
- Healthcare Coverage
- Number of Chronic Conditions
- Long-term Chronic Condition

**Dataset:** `Healthcare Analytics for Doctor Visits - VOIS.csv`

## Data Visualization

The project uses different visualization techniques to explore distributions, comparisons, trends, and relationships in the healthcare data.

### Visualizations

- Age Distribution – Histogram
- Gender Distribution – Pie Chart
- Patient Visits – Count Plot
- Patient Distribution by Illness – Bar Chart
- Health Status Distribution – Donut Chart
- Average Visits by Gender – Bar Plot
- Illness Score vs. Average Doctor Visits – Line Chart
- Healthcare Variables Correlation – Heatmap
- Reduced Activity by Chronic Condition and Gender – Grouped Bar Chart
- Doctor Visits by Illness Score – Box Plot
- Age vs. Doctor Visits by Gender – Scatter Plot
